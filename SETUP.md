# Profile setup

Publish these files to the public `pathum-sb/pathum-sb` repository, with `main` as the default branch. GitHub displays its root README on the matching user's profile.

1. Sign in to GitHub with an account that can write to `pathum-sb/pathum-sb`.
2. Upload or commit `README.md`, `assets/`, and `.gitignore` to `main`. Keep an existing repository's history when publishing.
3. Check the profile in GitHub's light and dark themes and at a narrow viewport.

The contribution calendar, analytics, badges, and technology icons use third-party services and can be temporarily unavailable or cached. Their alternative text and the profile links remain available.

SVG animations are decorative and run automatically inside images; the README links supply the click targets. Reduced-motion preferences disable custom CSS animations in supporting viewers. GitHub's Markdown renderer controls layout and may differ from a local preview.
